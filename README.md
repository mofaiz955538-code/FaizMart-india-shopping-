# FAIZMART INDIA SHOPPING V50 — APK Build Ready

This project wraps the saved FAIZMART V50 web app in a native Android WebView shell.

## Build
- Android Studio/Gradle: Gradle 8.7, Android Gradle Plugin 8.6.1, Java 17, compileSdk 35.
- GitHub Actions: open **Actions → Build FAIZMART V50 APK → Run workflow**. After it finishes, open the workflow run and download **FAIZMART-V50-debug-apk** from Artifacts.

## Important
The V50 HTML currently stores products/orders locally on the device/browser. It is not yet a cross-device online marketplace backend.
